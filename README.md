# Асамблея ОМБ

Ролевая веб-Асамблея Организации Мировой Безопасности в эстетике конца 1980-х:
зал заседаний, делегации, президиум, резолюции, голосования, чат и архив
документов. Статический сайт без сборщика и внешних библиотек.

- Живая версия: GitHub Pages (адрес появится после публикации).
- Документация: [docs/README.md](docs/README.md) и [docs/SPEC.md](docs/SPEC.md).

## Возможности

- Регистрация и вход по логину и паролю; пароли хранятся только хэшами
  PBKDF2-SHA256.
- Две роли в заседании: дипломат и наблюдатель; президиум из двух председателей
  назначается паролем президиума.
- Скрытая служебная панель: схема зала 12–80 мест, управление пользователями,
  паролями и архивом.
- Чат «Канал» и личные сообщения «Шёпот», очередь слова, резолюции и правки,
  голосования, журнал заседания.
- Экспорт документов и протокола в PNG, DOCX и печать в PDF.
- Полная мобильная версия: нижняя навигация, шторки панелей, чат.

## Важно про данные

Сайт полностью статический. Состояние заседания и чат сохраняются в браузере
каждого участника (localStorage/IndexedDB) и **не синхронизируются между
устройствами**. Для общей игры на одном экране это работает; для общения
участников с разных устройств нужен сервер (Supabase или аналог) — см.
[docs/SPEC.md](docs/SPEC.md). Обсуждение и обратная связь — через Issues этого
репозитория.

## Локальный запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
node server.js
```

По умолчанию: http://localhost:8080. Также можно открыть
`OMB-Asambleya-beta.html` — собранную версию «всё в одном файле» (создаётся
скриптом `_tools/build-single.js`).

## Структура

```text
index.html      — SPA, hash-роуты #/hall, #/archive
css/            — base, layout, hall, components, documents, print
js/             — store, api, rules, auth, export, docx, idb, audio, utils
js/ui/          — экраны и панели интерфейса
assets/         — эмблема и шрифты PT Mono, Oswald
images/         — фактуры и фоны
docs/           — README и SPEC
```

## Публикация

Сайт размещён на GitHub Pages из ветки `main`, каталог `/` (файл `.nojekyll`
отключает обработку Jekyll). Секретов в репозитории нет: только хэши паролей.
