# Асамблея ОМБ

Ролевая веб-Асамблея Организации Мировой Безопасности в эстетике конца 1980-х:
зал заседаний, делегации, президиум, резолюции, голосования, чат и архив
документов. Статический сайт без сборщика и внешних библиотек.

- Живая версия: https://wetali30-maker.github.io/omb-asambleya/
- Репозиторий: https://github.com/wetali30-maker/omb-asambleya
- Документация: [docs/README.md](docs/README.md) и [docs/SPEC.md](docs/SPEC.md).

## Возможности

- Регистрация и вход по логину и паролю; пароли хранятся только хэшами
  PBKDF2-SHA256.
- Две роли в заседании: дипломат и наблюдатель; президиум из двух председателей
  назначается паролем президиума.
- Скрытая служебная панель: схема зала 12–80 мест, управление пользователями,
  паролями и архивом.
- Чат «Канал» и личные сообщения «Шёпот», очередь слова, резолюции и правки,
  голосования, журнал заседания.
- Экспорт документов и протокола в PNG, DOCX и печать в PDF.
- Общий зал: совместное заседание с друзьями по коду комнаты и ссылке‑приглашению
  в реальном времени (публичный MQTT‑брокер, без сервера).
- Полная мобильная версия: нижняя навигация, шторки панелей, чат.

## Общий зал — игра с друзьями

Чтобы вести заседание вместе с друзьями с разных устройств, нужен общий зал:

1. Откройте статус‑строку внизу (или «Ещё → Общий зал» на телефоне), укажите
   имя и нажмите «Создать зал» — появится код из шести символов и ссылка‑приглашение.
2. Отправьте ссылку друзьям. Открыв её, они попадают в тот же зал: заседание,
   делегации, чат, резолюции, голосования, посадка в зал и настройки
   синхронизируются в реальном времени.
3. Внутри зала видно список участников; выйти можно кнопкой «Покинуть зал».

Синхронизация идёт через публичные MQTT‑брокеры (HiveMQ и EMQX) прямо из
браузера, без регистрации и сервера. Код зала — единственная защита: кто знает
код, видит и меняет заседание, поэтому не публикуйте ссылку открыто. Брокер
тоже публичный — не передавайте там ничего чувствительного. Без зала сайт
работает как раньше: состояние хранится только в браузере.

Имя для общего зала берётся из профиля дипломата или указывается вручную.
Каждый участник регистрирует своего дипломата сам: правило «одна страна — один
голос» действует на всех, а повторная регистрация страны возможна только как
член делегации без права голоса.

## Локальный запуск

Сайт использует ES-модули, поэтому открывать `index.html` напрямую из файловой
системы нельзя — нужен HTTP. Запустите статический сервер:

```bash
node server.js
```

По умолчанию: http://localhost:8080. Сборка «всё в одном файле»
(`OMB-Asambleya-beta.html`) и скрипт `_tools/build-single.js` в репозиторий не
входят: это локальные артефакты для бета-тестеров.

## Структура

```text
index.html      — SPA, hash-роуты #/hall, #/archive
css/            — base, layout, hall, components, documents, print
js/             — store, api, rules, auth, export, docx, idb, audio, net, utils
js/ui/          — экраны и панели интерфейса (включая network.js — общий зал)
assets/         — эмблема и шрифты PT Mono, Oswald
images/         — фактуры и фоны
docs/           — README и SPEC
```

## Публикация

Сайт размещён на GitHub Pages из ветки `main`, каталог `/` (файл `.nojekyll`
отключает обработку Jekyll). Секретов в репозитории нет: только хэши паролей.
