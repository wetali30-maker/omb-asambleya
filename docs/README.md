# Асамблея ОМБ — Организация Мировой Безопасности

Ролевая веб‑игра: зал заседаний 1980‑х, два председателя, делегации и наблюдатели,
очередь слова, резолюции и правки, голосования, автоматические документы и архив.
Полностью статический сайт — без сборки и зависимостей. Для совместной игры
с друзьями есть «Общий зал» с синхронизацией через публичный MQTT‑брокер.

Живая версия: https://wetali30-maker.github.io/omb-asambleya/

---

## Быстрый запуск

Нужен любой статический сервер. В репозитории есть свой, без зависимостей
(Node.js 18+):

```bash
node server.js
# Откройте http://localhost:8080
```

Порт можно изменить: `PORT=8081 node server.js` (PowerShell:
`$env:PORT=8081; node server.js`).

Альтернативы:

```bash
python -m http.server 8080
# или
npx serve .
```

Открывать `index.html` двойным кликом нельзя: ES‑модули и IndexedDB требуют
HTTP‑протокола (file:// заблокирует импорты).

## Первые шаги

1. Зарегистрируйте дипломатов: у каждого аккаунта есть **логин и пароль**
   (от 6 символов). Пароли хранятся только как PBKDF2‑SHA256‑хэш.
2. Нажмите «Назначить президиум» и посадите в кресла двух глав делегаций —
   для назначения нужен **пароль президиума**, известный только председателям.
   Председатель — кресло 1, сопредседатель — кресло 2.
3. Выберите дипломата в шапке: при входе система попросит его логин и пароль.
   Действия выполняются от имени вошедшего: посадка в зал, чат, запрос слова,
   резолюции, голос.
4. Председатель в кресле открывает голосование из пульта или карточки резолюции,
   закрывает его и формирует протокол заседания из пульта/сводки.

Правила: одна страна — один голос; наблюдатели не голосуют и не вносят
резолюции; голосование открывает и закрывает только председатель в кресле;
резолюция принята, если кворум соблюдён и «за» больше, чем «против».

## Общий зал (игра с друзьями)

1. Клик по чипу «Общий зал» в статус‑строке (на телефоне — «Ещё → Общий зал»).
   Укажите имя и нажмите «Создать зал» — получите код и ссылку‑приглашение.
2. Друзья открывают ссылку (`?room=КОД`) и сразу попадают в тот же зал.
3. Синхронизируются: дипломаты и входы, чат и шёпот, слово, резолюции и правки,
   голосования и бюллетени, посадка в зал, президиум, настройки заседания,
   таймер, журнал и архив. Аватары и флаги передаются отдельно (до ~240 КБ).
4. Кнопка «Покинуть зал» отключает синхронизацию; заседание остаётся в браузере.

Как это устроено: изменения расходятся патчами по MQTT 3.1.1 поверх WebSocket.
Каждая запись сравнивается по отметке времени (последняя правка побеждает),
удаления помечаются «могильными» метками, при расхождении участники обмениваются
полными снимками. Переключение идёт между `broker.hivemq.com` и `broker.emqx.io`.

Ограничения: брокеры публичные, шифрования нет — код зала служит единственной
защитой; в зале видны данные всех, кто знает код, а последний снимок зала
хранится у брокера и выдаётся каждому новому участнику. Локальные настройки
(звук, выбранный дипломат) остаются у каждого свои. Первое вхождение в зал
заменяет локальное заседание снимком комнаты; прежнее состояние сохраняется
в резервной копии (`omb.prejoin.v1`). Фоновая вкладка может принимать
обновления с задержкой несколько секунд — активная вкладка обновляется сразу.

## Роли и доступ

- **Дипломат** — логин/пароль, место в зале, слово, резолюции, голос.
- **Наблюдатель** — присутствует и говорит, но не голосует.
- **Председатели (2)** — регламент, голосования, модерация чата, удаление
  резолюций, управление заседанием. Назначаются паролем президиума; пароль
  нигде на сайте не отображается и не подсказывается.
- **Администраторы (ровно 3)** — уровень выше президиума: схема зала (12–80
  мест), смена пароля президиума, назначение/снятие председателей, блокировка
  и удаление пользователей, смена паролей администраторов, очистка архива,
  новое заседание и полный сброс.

Вход администратора скрыт: семь быстрых нажатий по эмблеме в шапке или
удержание 1,6 с. На телефоне — «Ещё → Вход» для дипломатов; служебный вход
для администраторов доступен тем же скрытым жестом. Пароли администраторов
заданы хэшами в `js/store.js` и не публикуются в интерфейсе.

## Состав интерфейса

- **Слева** — заседание (часы, длительность, кворум, два кресла), делегации,
  очередь слова.
- **Центр** — SVG‑зал на 12–80 мест (настраивается администратором), президиум,
  лист сводки на столе, часы, зум и полноэкранный режим, легенда, полоса
  голосования.
- **Справа** — «Канал» (общий и «Шёпот» — личные сообщения), «Резолюции»,
  «Журнал».
- **Сверху** — шапка с кворумом, таймером, резолюцией, архивом, профилем, пультом,
  звуком и настройками.
- **Снизу** — бегущая лента событий и статус‑строка.
- На планшете/телефоне — нижняя навигация и шторки; чат и резолюции открываются
  отдельной вкладкой.

## Данные и резервные копии

- Состояние — `localStorage` (`omb.state.v1`), изображения — IndexedDB (`omb.db`).
- «Настройки → Экспорт JSON» сохраняет состояние и изображения в один файл;
  «Импорт JSON» восстанавливает архив.
- «Новое заседание» освобождает зал, сохраняя дипломатов, президиум и архив.
- «Полный сброс» удаляет всё без возможности восстановления.
- Данные привязаны к браузеру и адресу; очистка данных сайта их удаляет.
- В общем зале данные дополнительно хранятся у каждого участника и сходятся
  после переподключения. Настройки сети — `omb.net.v1`, метки удалений —
  `omb.net.tomb.v1`, резервная копия до входа — `omb.prejoin.v1`.
- Логины и пароли — игровые, но хранятся правильно: только соль и хэш
  PBKDF2‑SHA256 (120 000 итераций). В статической версии это защита от
  случайного просмотра; полноценная серверная проверка описана в SPEC.
  Резервная копия содержит хэши — не публикуйте файл.

## Адаптивность

Проверено на ширинах 360, 480, 768, 1024, 1440 px и в ландшафте телефона.
Зал масштабируется целиком, панели становятся шторками, кнопки голосования
растягиваются на всю ширину, тикер/статус скрываются в ландшафте, чтобы отдать
место залу.

## Публикация на GitHub Pages

Сайт размещён на GitHub Pages: https://wetali30-maker.github.io/omb-asambleya/
(ветка `main`, каталог `/`, файл `.nojekyll` отключает обработку Jekyll). Все
пути относительные, поэтому подкаталог репозитория работает без правок.

В репозиторий не попадают служебные файлы: `_tools/` и собранный
`OMB-Asambleya-beta.html` (перечислены в `.gitignore`). Секретов в коде нет —
только хэши паролей; логины администраторов и пароль президиума в документации
не публикуются.

Сайт статический. Без общего зала заседание и чат живут в браузере каждого
участника; для совместной игры с разных устройств создайте зал (см. выше) или
разверните собственный брокер. Обратная связь — через Issues репозитория.

## Проверка кода

Сборки нет; синтаксис модулей проверяется напрямую:

```bash
node --check js/main.js
# при желании — по всем файлам js/
```

Приложение протестировано локально в браузере: регистрация по логину/паролю,
вход и смена пароля, назначение двух председателей паролем президиума,
блокировка и разбан, слово и регламент, резолюции и правки, удаление сообщений
и резолюций председателем, голосования и автоархив, протокол (PNG/PDF/DOCX),
схема зала 12–80 мест, скрытая админ-панель, настройки, экспорт/импорт,
адаптивные режимы.
